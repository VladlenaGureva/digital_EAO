**О проекте**

**По следам искателей счастья: разработка цифрового туристического маршрута в Еврейскую автономную область на основе корпуса устных свидетельств**

Проект создан на основе корпуса устных свидетельств – 57 интервью с жителями ЕАО, экспертами в области культуры и эмигрантами, собранных в ходе этнографической экспедиции АНО Научно-гуманитарный Центр «Сэфер» (2025). Также используются фотографии из личных архивов информантов, экспедиционные снимки, архивные документы и опубликованные материалы.

**Задача (от Центра "Сэфер"):** цифровой туристический маршрут на основе экспедиционных материалов, реализованный в виде интерактивной веб-карты.

В центре проекта 3 больших вопроса:
*   Какие места, упомянутые в корпусе устных свидетельств, включить в маршрут?
*   Как эти места извлечь из корпуса устных свидетельств?
*   Как репрезентировать маршрут в цифровой среде?

**Методика извлечения мест из корпуса интервью**
1. Первчная тематическая разметка, выполненная в базе данных Центра "Сэфер" "SFIRA" по гайду этнографической экспедиции.
2. Вторичное семантическое кодирование, в ходе которого разработан и применен Codebook, объединяющий концепции гуманистической географии (sense of place), memory studies (подход П. Нора), семиотики культуры (подход Ю.М. Лотмана), мифогеографии (подход И.И. Митина) и критической ГИС.
3. Для ускорения семантической разметки создан полуавтоматический инструмент - веб-приложение semantic_coder.html, которое на основе статистики сочетаний тематических тегов первичной разметки предлагает семантические коды.
4. В результате семантического кодирование выделено 132 места, значимых для информантов ЕАО. Из них 90 отобраны для отображения на интерактивной карте по критериям семантической насыщенности, географической репрезентативности и доступности.

**Структура данных и создание карты**

Все данные систематизированы в Excel-файле (Датасет.xlsx) с листами:
*  places – географические координаты мест, краткая историческая справка о них.
*  audio – привязка аудиофрагментов к месту и тематическому слою, метаданные информанта, транскрипт аудиофрагмента.
*  photo – фотографии мест с подписями и источниками.
*  routes – линейные объекты миграционных волн ЕАО разного времени (маршрутов искателей счастья).

Python-скрипты автоматически генерируют:
*  places.geojson – точечные объекты для карты
*  отдельные place_id.json для каждого места (историческая справка, аудио, фото)
*  routes.geojson для маршрутов

**Интерактивная карта**

Библиотеки, которые использовались при создании карты: Leaflet и OpenStreetMap (OSM).

Реализованные сценарии взаимодействия пользователя с картой:
1. Фильтрация объектов по тематическим слоям:
   *  Маршруты искателей счастья (миграционные волны ЕАО)
   *  Места памяти (Репрессии, Великая Отечественная война, Холокост)
   *  Народная топонимика
   *  Идентичность места
   *  Идентификация с местом
2. При клике на маркер объекта - открывается нижняя панель с информацией о месте, которая включает краткую историческую справку, аудифорагменты, относящиеся к месту и фотографии.
3. При клике на линию маршрута - открывается нижняя панель с информацией о миграционной волне, аудиофрагментами о различных аспектах переезда, фотографии.
4. Реализован принцип палимпсеста места - один объект может принадлежать разным тематическим слоям и содержать противоречащие или дополняющие друг друга устные свидетельства.

**UX-тестирование**

В рамках разработки интерактивной карты проведено асинхронное UX-тестирование с 10 респондентами (анкетирование после знакомства с картой). 
Выявленные проблемы и доработки:
*  Увеличена область клика по линии маршрута на карте
*  Усилено визуальное выделение активной вкладки слоя в нижней панели
*  Раздел "О проекте" и "Как читать карту" разделены на два смысловых блока
*  В разделе "О проекте" размещены фотографии экспедиции
*  При обновлении страницы с картой сохраняется последний активный выбор пользователя

**Как запустить проект (локально)**
1. Склонировать репозиторий
2. Перейти в корневую папку проекта
3. Открыть index.html в браузере
4. Для обновления данных:
*  отредактируйте Датасет.xlsx
*  запустите скрипты places.py и generate_place_jsons.py
*  замените сгенерированные файлы в папках places/ и routes/
